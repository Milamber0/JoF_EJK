# Settings icons

The settings menu's icons ([settings_icons.rs](../../src/settings_icons.rs)): grey
metal discs in the quick wheels' style ([assets/wheel](../wheel/README.md)),
generated by Sol as one icon board (`Game_UI_icon_design_board_2K_20261007145838`,
07/10/2026, kept outside the repository) and cut out by
[settings_icons.py](../../../../scripts/settings_icons.py). They are SJK's own art;
no retail image is used. Gold-on-navy and holocron-face sets replaced them on
13/10/2026; Sol brought the grey discs back on 15/10/2026.

Each is 128x128, the UI atlas cell, on transparency with an anti-aliased round edge.
The classic Settings group lists use twenty of them (`Entry::icon` in
[layout.rs](../../src/menu/classic/layout.rs)); settings, key_bindings, options,
text, camera, crosshair, nameplates, identity, changelog, credits, update and
import are spares for other screens.

## Regenerating

With Python 3 and Pillow, numpy and scipy (`pip install pillow numpy scipy`), from
the repository root:

```sh
python scripts/settings_icons.py Game_UI_icon_design_board_2K_20261007145838.jpg crates/sjk-viewer/assets/settings
```

The script finds the board's 32 discs (four rows of eight) and names them in board
order: settings, key_bindings, options, first_setup, graphics, sound, gameplay,
network; movement, interaction, weapons, force_powers, mouse_joystick,
other_controls, game_options, interface; hud, scoreboard, video, image, lighting,
shadows, weather, text; camera, crosshair, nameplates, identity, changelog,
credits, update, import.
