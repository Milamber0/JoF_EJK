# Quick wheel icons

The quick wheel's icons ([catalog.rs](../../src/quick_wheel/catalog.rs)): grey metal
discs in the style of Jedi Academy's neutral Force icons, generated by Sol as two
icon boards (kept outside the repository) and cut out by
[wheel_icons.py](../../../../scripts/wheel_icons.py). They are SJK's own art; no
retail image is used.

Each is 128x128, the UI atlas cell, on transparency with an anti-aliased round edge.

- The first board, `Game_HUD_icon_design_board_2K` (07/10/2026): its last two rows,
  sixteen discs: the weather, the first General choices, and `sun.png` and
  `moon.png`, spares that became the Day and Night choices (08/10/2026).
- The second board, `Game_HUD_icon_design_board_2K_20261008102726` (08/10/2026):
  four rows of seven, each named by the action it is for, then `custom.png`
  (braces round a dot), the picture of every custom console command, and
  `quick_wheel.png` (a ring of discs), which Settings' Quick wheel category wears
  on its rail.

Every action has its icon. `illuminate` (the Toys page's choice) is not cut from a
board: it is the holocron picture the client bundles
([holocron](../holocron/README.md), `toy_illuminate.png`, 128x128 as these are).
The atlas gives the wheel three rows of cells (`ui_renderer::WHEEL_ICON_CELLS`, 48),
so three more icons fit before it needs another row.

## Regenerating

With Python 3 and Pillow, numpy and scipy (`pip install pillow numpy scipy`), from
the repository root:

```sh
python scripts/wheel_icons.py Game_HUD_icon_design_board_2K.jpg crates/sjk-viewer/assets/wheel
python scripts/wheel_icons.py Game_HUD_icon_design_board_2K_20261008102726.jpg crates/sjk-viewer/assets/wheel second
```

The script finds a board's grey discs and names them in board order, row by row,
from the board's list (`BOARDS`; `first` is the default):

- `first`, the sixteen discs of its lower half: drizzle, rain, storm, snow,
  ground_fog, clouds, maps_own, weather_off, then third_person, nameplates,
  screenshot, hud, afk, cosmetics, sun, moon.
- `second`, all 28: game_menu, first_setup, free_camera, timer, fps, speedometer,
  lagometer; console, whats_new, team_menu, spectate, respawn, inspect, duel;
  saber_style, saber_toggle, taunt, bow, meditate, flourish, gloat; vote_yes,
  vote_no, record, stop_record, reconnect, custom, quick_wheel.

Its discs are about 167 pixels round against the first board's 135, so the cut runs
3.7 pixels inside their rim instead of 3: the same share of the disc, so both sets
come out the same size (the alpha edge crosses half at 61.75 pixels from the
middle in every icon). Cutting the first board again gives its sixteen icons back
byte for byte.
